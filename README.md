# 🏆 赌狗.skill

> 马无夜草不肥，人无横财不富。2026 世界杯来了，你懂什么叫梭哈吗？
>
> 支持 **OpenCode** / **Claude Code** / **Codex** / 任意 agent。

---

## 🤔 这玩意儿干嘛的

世界杯 72 场比赛，每场 AI 帮你跑四个维度的分析：

| 维度 | 权重 | 看什么 |
|------|------|--------|
| 欧赔 | 30% | 180+ 家公司赔率走势、凯利指数有没有鬼、初盘到即时赔率是升是降 |
| 亚盘 | 35% | 盘口升了还是降了、水位是高是低、庄家到底在诱盘还是真有信心 |
| 大小球 | 15% | 大小盘在升还是在降，市场到底觉得是大球还是小球 |
| 历史数据 | 20% | 这队在这盘口下历史赢盘率多少，是真有实力还是纸老虎 |

最后给个综合评分 + 推荐方向 + 风险提示。当然，仅供参考，**梭哈之前想清楚**。

## 📦 安装

随便找个你用的 AI 助手，把目录拷过去就行：

```bash
# OpenCode 用户
cp -r betdog-skill ~/.config/opencode/skills/

# Claude Code 用户
cp -r betdog-skill ~/.claude/skills/

# Codex 用户 (OpenAI)
cp -r betdog-skill ~/.codex/skills/

# 其他 agent / 项目级
cp -r betdog-skill .opencode/skills/
cp -r betdog-skill .claude/skills/
cp -r betdog-skill .agents/skills/
```

然后跑一下装依赖（就一次）：

```bash
bash betdog-skill/setup.sh
```

完事。就这么简单，不需要什么 API Key，不需要什么 Puppeteer，纯 HTTP 抓数据。

## 🎮 怎么用

对着你的 AI 助手说人话就行：

```
帮我预测一下 墨西哥 VS 南非，今晚梭不梭
```

```
世界杯今天有啥比赛？推荐一场
```

```
巴西 vs 摩洛哥 怎么买
```

AI 会自动跑脚本、扒数据、出报告。

当然你也可以手动跑，看看底层数据长啥样：

```bash
# 看赛程表
node schedule.mjs

# 预测一场 (2906701 是墨西哥 vs 南非)
node predict.mjs 2906701

# 把原始数据导出来自己分析
node fetch.mjs 2906701
```
